# 私校退休金與人事成本決策平台（台灣私校編制內 vs. 約聘雇）

一套**零外部相依、可完全離線與 GitHub Pages 線上運作**的互動式精算與決策工具組，依據台灣現行最新法規與官方費率分級表，完整比較「**一般勞工／校內約聘雇（勞保＋勞退新制＋健保表三）**」與「**私校編制內職員（公保＋私校退撫儲金＋健保表二）**」之**員工退休金**與**雇主聘用成本**。

## 快速體驗（GitHub Pages 線上版／本機離線版）

- **三合一統合平台主入口**：[`index.html`](index.html)（與 [`私校退休與人事成本決策平台.html`](私校退休與人事成本決策平台.html) 內容相同）

## 內建官方公開法規與費率基準

本專案各項查表計算均依據以下中華民國公開法規與官方表件（已內嵌於互動網頁引擎中，離線執行無須外部讀檔）：

1. **《勞工保險條例》**（民國 115 年 01 月 21 日修正）＆ **116.01.01 適用勞保普通事故（12%）＋就保（1%）保險費分擔金額表**（全時 10 級：30,900～45,800 元）
2. **《勞工退休金條例》**（民國 108 年 05 月 15 日修正）＆ **116.01.01 生效勞工退休金月提繳分級表**（62 級：1,500～150,000 元）
3. **《公教人員保險法》**（民國 113 年 01 月 03 日修正）＆ **114.01.01 實施私校教職員保險薪額表**（39 級：90～770 薪額，17,390～63,570 元）
4. **《學校法人及其所屬私立學校教職員退休撫卹離職資遣條例》**（民國 112 年 06 月 09 日修正）＆ **114.01.01 生效私校退撫每月提撥儲金費用表**（本薪×2×12%，個人 35%／學校 32.5%／政府 32.5%）
5. **115.01.01 實施健保保險費負擔金額表（二）私立學校教職員**（個人 30%／學校 35%／政府 35%，1.56 人）＆ **表（三）一般受僱者**（個人 30%／單位 60%／政府 10%，1.56 人）

> **免責聲明**：本專案為法規與財務試算分析模型，所列薪級級距係以實務範例參數建立，僅供學術研究、人事預算模擬與個人職涯參考；實際退休給付與保費負擔請以勞工保險局、臺灣銀行公教保險部、私校退撫儲金管理委員會、健保署及各校人事室之正式核定為準。

## 啟用 GitHub Pages 步驟

1. 將檔案上傳至本儲存庫的 `main` 分支根目錄（確認包含 `index.html`）。
2. 進入儲存庫頁面上方的 **Settings** → 左側選單 **Pages**。
3. 在 **Build and deployment** → **Source** 選擇 **Deploy from a branch**。
4. Branch 選擇 **`main`**、資料夾選擇 **`/ (root)`**，點選 **Save**。
5. 等待約 1～2 分鐘重新整理頁面，上方即會顯示公開網址 `https://<您的帳號>.github.io/<儲存庫名稱>/`，點開即可直接操作三合一互動決策平台。
